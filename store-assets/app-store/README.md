# Telemob App Store assets

The six upload-ready screenshots in `iphone-6.9-screenshots` are 1290 × 2796
RGB PNGs without transparency. They use Apple's accepted 6.9-inch portrait
dimensions and can be uploaded in numeric order.

1. `01-connect-to-your-cluster.png`
2. `02-passkey-or-totp.png`
3. `03-find-the-right-node.png`
4. `04-native-mobile-terminal.png`
5. `05-run-commands-anywhere.png`
6. `06-keep-sessions-active.png`

The UI shown in the assets comes from Telemob's deterministic offline web demo.
It contains generic hosts and no real credentials, IP addresses, or terminal
data. The surrounding artwork is generated deterministically by
`scripts/build-app-store-assets.py` from the audited Google Play screenshots.

`iphone-6.9-screenshots-preview.png` is a contact sheet for review and should
not be uploaded to App Store Connect.
