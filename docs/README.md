# Telemob documentation

Telemob is an unofficial, independent open-source client. It is not affiliated
with, endorsed by, or maintained by Gravitational Inc. or the Teleport project.

- [Architecture](architecture.md) — runtime boundaries, authentication,
  terminal rendering, session ownership, and trust model.
- [Development](development.md) — prerequisites, local builds, validation, and
  generated artifacts.
- [Privacy and data flow](privacy.md) — credentials, storage, network
  destinations, device access, and insecure TLS.
- [Releases](releases.md) — stable/beta tags, EAS profiles, credentials, and
  GitHub Actions behavior.
- [Terminal keyboard](terminal-keyboard.md) — key rail, direct input, modifiers,
  and mouse-event behavior.

The public project overview, compatibility notice, credits, and license are in
the repository [README](../README.md).
